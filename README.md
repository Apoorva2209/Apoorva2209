# Hi, I'm Apoorva SV 👋

I build practical cybersecurity tools, with a focus on helping people in India avoid online scams.

## What I'm working on

### 🛡️ [JanVaani](https://github.com/Apoorva2209/janvaani-cyberguard-india)
A cyber-safety app that spots scam messages, links and calls and shows how to report fraud. One codebase ships as native apps for **Android, iOS, Windows and macOS**, an app for **Linux**, and an SMS and voice service for **button phones**. On Android it checks incoming SMS, WhatsApp and email notifications automatically, on the phone.

**Download:** [latest release](https://github.com/Apoorva2209/janvaani-cyberguard-india/releases/latest)

### 🔍 [Elevate Labs cybersecurity projects](https://github.com/Apoorva2209/ELEVATE-LABS-PROJECTS)
Hands-on lab tasks from my cybersecurity internship, starting with network scanning and port analysis using Nmap.
